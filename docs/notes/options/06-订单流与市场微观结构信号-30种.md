# 订单流与市场微观结构信号 30 种

> 来源：小红书清单式笔记（rednote ID 580133023），整理自 `docs/screenshots/options/` 截图。
> 主题：现货 / 订单流（order flow）与市场微观结构层面的 30 类常用信号与读法。与期权 GEX/Flow 互为补充——本清单关注的是 tape / order book / 成交结构本身。

---

1. **成交量柱（Footprint / Volume at Price）**：通过在每个价格点看到买/卖成交量来辨别哪一侧在「付出成本」成交，从而判断短期方向或吸收/推进力量。

2. **买卖力差（Delta / Signed Volume）**：用买入成交量减去卖出成交量来衡量主动买/卖压强，正（负）值提示多头（空头）主导。

3. **订单簿深度（Order Book Depth / DOM）**：观察限价盘中不同价位的挂单大小与变化，判断潜在支撑/阻力与流动性缺口。

4. **盘口不平衡（Imbalance）**：当某价位或拍卖阶段买/卖单远超另一侧时，说明短期会出现方向性移位或价差回补。

5. **扫盘/吃单（Liquidity Sweep / Sweep）**：突然的大量市价成交穿透多个价位，代表有冲击性流入/流出并可能引发趋势延续或瞬间回档。

6. **吸收（Absorption）**：一侧大量市价发力但对手挂单持续消化，表明更强的隐藏对手在接盘或卸货，价格可能反转或停滞。

7. **冰山单检测（Iceberg / Hidden Liquidity）**：连续小量成交反复出现同一挂单价，提示有隐藏/分批大单在支撑或压制价格。

8. **时间与销售（Time & Sales / Tape Reading）**：连续的小尺寸快速成交或大单突然出现能直接反映真实的主动流向与情绪冲击。

9. **买卖挂单撤单率（Order Cancel Rate）**：高撤单率说明算法/流动性提供者在探路或试探性挂单，表明"表面流动性"不可靠。

10. **主动/被动成交比（Aggressive vs Passive Flow）**：主动以市价成交的比例上升表示冲击性方向更强，反之被动成交多说明观望或做市平衡。

11. **成交簿倾斜（Book Pressure / Imbalance Ratio）**：买或卖侧挂单在短时间内大幅偏向，表示短期流动性偏向单一方向。

12. **成交量剖面（Volume Profile / VP）**：长期各价位累计成交量显示价值区间与重要支撑/阻力（高成交量区为价值区）。

13. **价量背离（Price-Volume Divergence）**：价格上升而流入成交量下降（或反之）提示行情可能失去动力并产生反转。

14. **开盘/收盘拍卖不平衡（Auction Imbalance）**：开盘或收盘拍卖时的单边成交量不平衡常预示全天或次日的主导方向。

15. **大单跟踪（Block Trade / Whale Flow）**：识别并跟随大块成交或机构分笔流出入，因为这些通常带有中短期实质头寸变化。

16. **流动性缺口（Liquidity Gaps）**：Order book 在某区间挂单稀少，价格易在缺口处快速滑移并加速趋势。

17. **滑点/执行成本异动（Slippage Signals）**：实际成交价显著偏离预期限价，说明市场瞬间流动性不稳或被冲击。

18. **追单/跟随扫单（Flow Chasing / Momentum from Sweeps）**：当连续扫盘带来持续主动流入，短线跟进可利用冲量延续。

19. **算法行为识别（Algo / Execution Pattern Detection）**：识别分片、TWAP/VWAP 等算法特征，区分真实方向性流与被动执行。

20. **盘口夹压（Squeeze between Liquidity）**：价格被两侧大单夹住后，一侧被突破时常有强烈快速移动。

21. **止损猎取（Stop-Hunting Patterns）**：流动性提供者通过短暂破位触发集中止损后迅速反向，识别可避免被动止损或捕捉反弹。

22. **流动性池迁移（Liquidity Migration）**：挂单从一个价位快速迁移到另一价位，表明资金重定价或交易员策略转换。

23. **成交速度/频率（Trade Rate / Trades-per-second）**：成交率骤增说明信息冲击到达或算法加速，往往伴随价格波动放大。

24. **买卖价差变化（Spread Dynamics）**：Bid-ask 价差突然扩大或收窄，反映流动性紧张或恢复与短期风险偏好变化。

25. **流向不一致信号（Flow vs Price Divergence）**：订单流显示一侧占优但价格未响应，提示大买/卖在被吸收或行情可能延迟反应。

26. **成交内在节奏（Microstructure Rhythm / Order Flow Patterns）**：市场在不同时间段（新闻、盘中整点）呈现可重复的流动性节奏，可用来规避或择机入场。

27. **对手盘行为识别（Counterparty Profiling）**：根据挂单与撤单频率、尺寸、分片特征推断是做市商、套利者还是机构，从而判断流的质量。

28. **流动性摩擦与滑动均值（Flow-adjusted VWAP / Impact Models）**：将成交冲击和可预期的执行成本计入价格期望以优化下单时机和尺寸。

29. **套利/对冲流（Cross-market Flow Detection）**：跨市场（期现、期权、相关品种）同时出现的订单流暗示套保或套利交易，可能推动主市场方向。

30. **流量毒性评估（Toxic Flow / Adverse Selection）**：判断流是否来自信息优势方（毒性高）以决定作为被动做市或主动避让的策略。

# Skew 的第一性原理

## 引子：不要把 skew 当成静态标签

在期权市场里，skew 经常被当成一个经验现象来使用：股指 Put 贵，商品 Call 贵，加密有时 Call 贵、有时 Put 贵。很多时候，这些结论本身并没有错，但如果只停在"哪个资产哪边贵"，就很容易把 skew 理解成一种静态标签。

更有价值的问题其实是：为什么一只标的的 skew 会有它自己的符号？为什么有些资产的左尾长期被高价定价，而有些资产的右尾更容易被市场买贵？如果把这个问题继续往下追，skew 就不只是 volatility smile 上的一段斜率，而会变成一条从期权价格、风险分布、spot-vol correlation，一直通向市场结构的判别链。

原文的核心不是给出某个单一结论，而是把不同资产的 skew 放进同一套框架里解释：skew 翘向哪边，最终取决于价格在极端状态下会被哪一股强制流撕裂。

## 一、Skew 不是情绪标签，而是风险中性分布的形状

理解 skew 的第一步，是先把 IV 还原成它真正代表的东西。期权价格本质上是风险中性概率下的期望 payoff，而 IV 只是这个价格的一种表达方式。单个期权的 IV 只能告诉我们某个 strike 上的定价水平；但当不同行权价的期权价格排在一起时，它们共同隐含了一整条风险中性分布。

这就是 **Breeden-Litzenberger** 框架的核心含义：期权价格曲线可以反推出 risk-neutral density。换句话说，volatility smile 并不只是交易屏幕上的一条曲线，它是市场对未来价格分布的一种压缩表达。

在这个视角下，skew 的符号有一个非常干净的翻译：

- **OTM Call 贵**，意味着高 strike 一侧的 IV 被抬升，对应风险中性分布的**右尾更肥**；
- **OTM Put 贵**，意味着低 strike 一侧的 IV 被抬升，对应风险中性分布的**左尾更肥**。

所以，"为什么 Call 贵"并不是一个单纯的期权报价问题。它真正等价于：为什么市场愿意给这只标的的右尾支付更高价格？同理，"为什么 Put 贵"也不是简单的看跌情绪，而是市场在给左尾风险支付更高保险费。

这一层转换很重要。因为它把 skew 从一个表层的价格现象，变成了一个尾部风险问题：市场真正定价的不是普通波动，而是极端路径会在哪一侧被放大。

## 二、Spot-vol correlation 决定 skew 的方向

如果 skew 描述的是哪一侧尾部更肥，那么下一个问题就是：为什么某一侧的尾部会变肥？

这里的中间变量是 **spot-vol correlation**，也就是标的价格变化与波动率变化之间的相关性。可以把它记作 ρ。

- 当 ρ > 0 时，价格上涨往往伴随波动率上升，市场更容易形成 **call-skew**；
- 当 ρ < 0 时，价格下跌往往伴随波动率上升，市场更容易形成 **put-skew**；
- 当 ρ 接近 0 时，smile 会更接近对称。

这个关系不是单纯的经验总结。在 Heston、SABR 这类随机波动率模型里，价格与波动率的相关系数 ρ 会直接影响 smile 的倾斜方向。ρ 为负，低 strike IV 更容易抬升；ρ 为正，高 strike IV 更容易抬升。

直观上，可以把波动率理解成价格路径的放大器。如果一只资产在上涨时波动率同步放大，那么上涨路径会被推得更远，右尾被拉长，高 strike Call 的价值上升，于是 call-skew 出现。反过来，如果一只资产在下跌时波动率同步放大，那么下跌路径会被进一步加速，左尾被拉肥，低 strike Put 被买贵，于是形成 put-skew。

同一件事也可以从期权的风险暴露来理解。持有 Call，本质上是 long delta 加 long vega。如果价格上涨时 vol 也上涨，Call 在上涨过程中会同时受益于方向和波动率，价格自然更高。持有 Put 则相反，它在下跌中获得方向收益，同时又受益于波动率上升。因此在"跌时 vol 爆"的市场里，Put 会天然更贵。

这就是 skew 的第一层机制：**波动率在哪个方向上放大价格路径，哪一侧的尾部就会变肥，哪一侧的期权就会更贵。**

## 三、真正的第一性问题：为什么相关性本身有符号？

只把 skew 追到 ρ 还不够。更底层的问题是：为什么不同资产的 spot-vol correlation 会有不同符号？为什么股指通常是负的，商品经常可以是正的，而加密又会在不同 regime 里来回切换？

这里需要从资产自身的经济结构和交易结构出发。学术上常见的解释至少有三条：**杠杆效应、波动率反馈，以及强制流的不对称。**

### 1. 杠杆效应（leverage effect）

杠杆效应是最直观的一层。对一家公司而言，股权是剩余索取权，可以理解为公司资产上的一个看涨期权。当股价下跌时，股权价值缩水，相对债务比例上升，股权变得更加杠杆化，于是股权波动率上升。这就形成了"价格下跌—杠杆上升—波动率上升"的负相关链条。

### 2. 波动率反馈（volatility feedback）

但杠杆效应不是唯一解释。波动率反馈提供了另一种因果方向：坏消息出现后，不确定性上升，投资者要求更高的风险溢价，折现率上升，资产价格立刻下跌。在这条链里，可以是波动率先上升，然后价格下跌，但结果同样表现为价格与波动率负相关。

### 3. 强制流的不对称（forced-flow asymmetry）

更贴近交易结构的一层，是强制流的不对称。很多市场的边际持有人既是多头，又带有某种形式的杠杆或风险预算约束。价格下跌时，追加保证金、风险平价降杠杆、vol-control 减仓、组合保险卖出、止损盘触发，会把卖出行为集中推向同一个方向。价格越跌，波动率越高；波动率越高，风险模型越要求降仓；降仓继续推动价格下跌。

关键在于，这种反身性通常是不对称的。市场下跌时，确实会有很多人被迫卖出；但市场上涨时，通常没有同等规模的资金因为"上涨"而被强制买入。于是负相关不仅来自公司资产负债表，也来自市场参与者的仓位结构、风控规则和被迫交易机制。

因此，skew 的底层判别式可以压缩成一句话：**看那股被强制的、反身的、会撞上硬约束的交易流指向哪边。它指向哪边，vol 就更容易在哪边爆发；vol 在哪边爆发，skew 就会翘向哪边。**

## 四、把这条链套到不同资产类

有了这条判别链之后，不同资产的 skew 形态就不再是零散经验，而可以被放进同一张谱系里。

```
FIG B.1 · skew 谱系 —— 由 spot-vol 相关性符号排序

  股指          单股          对称(ρ=0)      加密            商品
 强稳 put-skew  温和 put-skew              来回翻(regime)  偏 call-skew
 ←—— Put 贵 (ρ<0, 左尾肥) ————————————————— Call 贵 (ρ>0, 右尾肥) ——→
```

### 股指：强而稳定的 put-skew

股指是 put-skew 最稳定的资产之一。它的负 spot-vol correlation 同时受到几种机制推动：一是传统杠杆效应，二是波动率反馈，三是最重要的市场结构性去杠杆。

股指市场天然有大量 long-only 资金。养老金、共同基金、ETF、保险资金、机构组合，本质上都是风险资产多头。与此同时，很多策略又带有风险预算或波动率约束，例如 risk parity、vol-control、target-vol、组合保险类策略。当市场快速下跌时，这些资金会因为风控、波动率目标或保证金约束而被迫减仓。

于是股指下跌时，往往不是单纯的价格调整，而是会触发一条自我强化链：价格下跌，波动率上升；波动率上升，风险模型要求减仓；减仓带来更多卖压；卖压推动价格继续下跌。这个机制会持续把左尾拉肥。

所以，股指的 put-skew 并不是市场每天都在押注崩盘，而是市场知道：一旦左尾开始发生，资金结构会把它放大。低 strike Put 因此长期带有结构性溢价。

### 单股：也偏 Put，但通常浅得多

单股同样有杠杆效应，因此很多股票也表现为下跌时 vol 上升，整体偏 put-skew。但和指数相比，单股的 skew 通常更浅。

原因在于，指数的深 put-skew 主要来自系统性崩盘风险。系统性风险发生时，相关性上升，分散化失效，整个市场一起去杠杆，这类风险很难通过持有更多股票消除。单股则不同。个股除了系统性风险，还有大量特质风险，比如财报、并购、监管、产品周期、管理层变化、诉讼、行业事件。这些风险既可能向下，也可能向上，会把个股的分布拉得更分散，从而摊薄指数那种集中的左尾定价。

这也是为什么单股常见的是温和 put-skew，而不是指数那种深而稳的 put-skew。

同时，单股更容易出现反例。题材股、并购传闻标的、被大量做空的股票、轧空候选标的，强制流可能不是向下，而是向上。空头被迫回补，做市商被迫追 gamma，事件买盘集中涌入，都会让右尾突然变肥。在这些情况下，单股可以出现明显的 call-skew。

### 商品：短缺带来的 call-skew

商品市场的结构和股指不同。股指的极端风险多来自金融去杠杆和需求侧坍塌，而商品的极端风险经常来自供给侧冲击。

很多商品都有一个非常重要的物理约束：库存不能为负。供给短期无弹性时，一旦遇到战争、干旱、减产、运输中断或库存骤降，价格上涨可能不是线性的，而是带有很强的凸性。过剩可以被库存缓冲，价格往往是缓慢下行；短缺则可能突然撞墙，价格暴涨，同时不确定性暴涨。

这会形成正的 spot-vol correlation：价格上涨时，波动率也上升。上涨路径被放大，右尾变肥，高 strike Call 被更高定价，于是出现 call-skew。文献中常把这种现象称为商品里的 **inverse leverage effect**。

但商品不是铁律。天然气这类受库存、季节、运输约束明显的品种，call-skew 特征往往更典型；原油则更复杂，因为它既有供给冲击，也有需求崩塌和宏观金融属性，在某些阶段也可能表现出偏 put 的结构。商品 skew 的关键不是记住"商品 Call 贵"，而是判断这个品种真正的硬约束在哪一侧。

### 加密：forward-skew 的底色，以及频繁的 regime 翻面

加密资产经常被简单理解为"Call 贵"，但这个说法并不完整。更准确的表述是：加密带有 forward-skew 的底色，但会随着市场 regime 快速翻面。

在牛市或叙事扩散阶段，加密很容易出现右尾定价。杠杆永续合约、空头回补、现货追涨、FOMO 买盘、流动性涌入，以及期权市场里集中的 Call 买盘，都会让价格上涨和波动率上升同时发生。这时右尾被放大，Call-skew 会很明显。

但在危机阶段，加密又会迅速切换成 put-skew。2020 年 3 月、LUNA、FTX 这类事件中，市场结构会变成向下清算。杠杆多头被迫平仓，抵押品下跌触发更多清算，流动性抽走，做市商收缩风险，最终形成"跌—清算—更跌—vol 爆"的下行链条。

因此，加密真正的特征不是永远 call-skew，而是 regime 敏感。它既可以在狂热阶段把右尾定得很贵，也可以在崩盘阶段迅速变成深度 put-skew。对于加密，skew 本身往往就是市场状态的温度计。

## 五、实务上，信号不在绝对值，而在相对基线的偏离

理解 skew 的第一性原理之后，最重要的实务结论是：**不要用同一把尺子看所有资产。每个资产类都有自己的结构基线。**

股指本来就应该有较深的 put-skew，单股本来就通常比指数浅，部分商品天然偏 call-skew，加密则本来就会在不同 regime 之间移动。因此，单纯说某个标的"现在 Put 贵"或"现在 Call 贵"，信息量并不够。更重要的是，它相对于自己的历史基线偏离了多少。

比如，股指 Skew Slope 为正并不稀奇，因为这可能只是它的常态。但如果股指的 put-skew 异常收窄，甚至转成 call-skew，这反而值得关注，因为它意味着结构基线被打破。相反，一个商品出现 call-skew 也未必是强烈看涨信号，因为它可能本来就处在这样的结构里；只有当其 call-skew 显著超出自身历史分位，才更可能说明右尾风险被异常定价。

更完整的研究方式，是把 skew、价格路径、spot-vol correlation 和历史分位放在一起看。skew 抬升本身不够，必须判断它是恐慌驱动，还是追涨驱动。若价格下跌、ρ 转负、Put 抬升，通常更接近恐慌；若价格上涨、ρ 转正、Call 抬升，则更接近追涨或逼空状态。

在相对价值交易里，当某个标的的 25Δ RR 或 skew 指标冲到自身历史极端时，无论方向是 Put 过贵还是 Call 过贵，都可能提示均值回归机会。关键不是机械地卖 Put 或卖 Call，而是确认它是否真的偏离了自己的结构基线，以及这种偏离是否被当前价格和 spot-vol correlation 验证。

## 六、几个容易误判 skew 的地方

1. **把加密看成永远 Call 贵。** 加密确实有 forward-skew 的底色，但它不是恒定 call-skew。崩盘阶段的加密市场会迅速变成下行清算结构，Put-skew 可以在很短时间内接管整条曲面。用牛市样本外推整个资产类，很容易在 regime 切换时判断反向。

2. **把杠杆效应当成唯一解释。** 杠杆效应非常直观，但并不能解释所有负 skew。很多时候，波动率反馈、风险溢价变化和强制流结构才是更重要的来源。尤其是一些杠杆并不高、但仍然有明显 put-skew 的标的，背后往往不是资产负债表杠杆，而是市场参与者的仓位结构和风控机制。

3. **用指数的 skew 直觉套单股。** 指数的深 put-skew 很大程度上来自系统性崩盘风险，而单股的特质风险会摊薄这条左尾。直接拿指数的 skew 深度去要求个股，很容易把正常的个股结构误判成"Put 不够贵"或"保护不足"。

4. **只看 skew 的绝对值，不看历史分位。** 一个 Skew Slope 为 +10 的标的，看起来可能很恐慌，但如果它过去长期就在 +5 到 +15 之间波动，那么 +10 可能只是普通水平。Skew 必须放在自身历史分布和资产结构基线里理解，否则很容易把正常状态误读成信号。

## 结语：Skew 定价的是价格被迫撕裂的方向

Skew 不是简单的看涨或看跌指标。它更像是市场对极端路径的定价语言。Put 贵，未必代表市场单纯看跌；Call 贵，也未必代表市场一致看涨。更准确的说法是，市场在为某一侧更容易被放大的尾部风险支付价格。

- 股指的 put-skew，来自下跌时的杠杆效应、波动率反馈和强制去杠杆结构；
- 商品的 call-skew，来自短缺、库存约束和供给冲击下的上行凸性；
- 加密的 skew，则来自杠杆结构、叙事扩散和清算机制之间的 regime 切换。

因此，分析 skew 最有用的方式，不是记住某类资产"应该哪边贵"，而是顺着这条链往下追：当前 skew 指向哪一侧尾部？这一侧尾部是否符合该资产的结构基线？spot-vol correlation 是否同步验证？极端行情里，到底是哪一边的资金会被迫交易？

最终的问题可以压缩成一句话：当价格真的被强制流撕裂时，它会朝哪个方向裂？

这也是 skew 的第一性原理所在。它不是一条 IV 曲线的斜率，而是市场结构在尾部风险上的投影。

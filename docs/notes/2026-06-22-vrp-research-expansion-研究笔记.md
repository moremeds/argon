## 1. 这次扩展在解决什么 —— "内在联系"

PR #147（VRP harvest markout）只回答了一个 cube 里的**一格**：`(asset_class × deviation_class)`、
单一 T+20、单一目标（harvest），而且前瞻 RV 用的是个**近似**。这次扩展把它做成一个
**统一的、测量被校正过的研究引擎**，五个清单项不是五条独立支线，而是同一个 markout 的两层：

```
              测量层（所有轴共用的地基）
   item 1 ─▶  用 corporate-action 调整后的价格，算精确的 [t,t+h] 前瞻 RV
   item 3 ─▶  历史财报日历（massive filing_date ∪ flow_events）+ filing 滞后缓冲
                                  ▲
            三个轴都坐在这个校正过的地基上：
   AXIS A (item 2) 条件粒度    AXIS B (item 4) 持仓期   AXIS C (item 5) 目标定义
   asset_class → ×sector       h ∈ {5,20,60}            harvest → 方向性 → ΔVRP 回归
```

**关键点**：如果 RV(t+h) 被污染（拆股看起来像 −90% 暴跌）或财报漏进 (t,t+h] 窗口，**每一个轴都会
报出有偏的数字**。所以即便五项"并行"开发，它们都消费**同一个校正过的核心**（`vrp_markout_core`）。

## 2. 这次扩展相对 v1（PR #147）的改进

一句话：v1 是**一个答案**，扩展是**一张地图** —— 而且顺手校正了 v1 赖以测量的那把尺子。四个层面的改进：

### 改进 1 —— 校正了测量层（地基）

v1 用 UW 的 `vrp_daily.rv`（trailing-21d 已实现波动率**近似**）给 harvest 打分。扩展改用**精确的、
corp-action 调整后的前瞻 RV**（拆股必调、分红可选，带"未调整拆股"防线），并配一张**历史财报日历**
剔除被财报污染的窗口。item 1 量化了旧尺子有多松（平均 `\|近似 − 精确\|`）：

| 持仓期 | 平均 \|偏差\|（vol pts） | corr |
|---|---|---|
| T+5 | **0.184** | 0.18 |
| T+20 | 0.135 | 0.14 |
| T+60 | 0.118 | 0.07 |

即每个 v1 裁决都带 ~0.13–0.18 vol pts 的测量噪声、短端最糟。下面所有轴都跑在**校正后的目标**上。

### 改进 2 —— 推翻了 v1 的核心结论（最大的赢面）

v1 把**所有单票塞进一个桶 → 裁决 NONE**（"别卖单票波动率"）。这是个**聚合假象**。按 sector 重新分桶
（item 2，51 行）后，单票波动率在**特定板块里是可卖的** —— Power / Space / Fintech / Crypto / M7 / SaaS
的 RICH 桶都过了可卖线。v1 的"否"变成"是，在**这里**"。这是定性**反转**，不是细化。

### 改进 3 —— 加了"时机"（item 4）

v1 只看一个持仓期。扫 T+5/20/60（36 行）显示 harvest 在 **~T+20 见顶、T+60 衰减**（单票 RICH 到 T+60
整桶掉出）。现在知道的是*最优持仓期*，而不只是"某处有 edge"。

### 改进 4 —— 加了两个全新的信号类型（item 5）

- **方向性（5a）**：高 VRP 单票**跑输**低 VRP 单票（BEARISH_TILT）—— 与 Bollerslev 的指数层效应相反，
  因为单票高 VRP = 被爆炒/拥挤的名字。
- **ΔVRP 回归（5b）**：贵 VRP **向下回归**，随持仓期增强、单票最强（single_name T+60 = **−0.105**；
  sector_etf −0.063；index_macro −0.060；credit −0.039）。

两者都是 v1 没有的维度。再叠加全程的 **OOS 纪律**（walk-forward 后 40% 留出 + 逐季度灾难闸，置信度封顶 "med"）。

**净改进**：v1 = "指数/ETF 的贵波动率在一个持仓期上可不可卖，是/否"。扩展 = "在**哪**、**何时**、朝**哪个方向**
—— 在校正后的尺子上测、并经样本外验证"。最可落地的单一增量是 item 2 的**板块反转**。

> **没改进的（诚实的保留）**：① 六张表**仍无人消费**（与被砍的 UI 卡片同一个缺口）；② 仍是 markout 研究、
> **不是可交易回测**（见 §3）；③ per-sector 的 n 更小，item 2 是"哪里值得看"而非无差别许可。

## 3. ⚠️ 这是 markout 信号研究，**不是**可交易回测（entry / exit / P&L 在哪？）

这是读这份笔记最该先搞清楚的一点。**本研究没有构造入场单、没有出场规则、也没有美元 P&L 或净值曲线。**
它回答的是"**这笔溢价在样本外稳不稳定地存在**"，而不是"**真金白银能赚多少**"。三者对照：

| 一个真实策略需要 | 本研究做了什么 |
|---|---|
| **入场（entry）**：哪个结构、哪条腿、哪个 strike、按什么价成交 | 只有一个**信号状态** `vrp_z ≥ +1.0`（RICH）。没有期权结构、没有 strike、没有委托单 |
| **出场（exit）**：固定到期 / 21-DTE 复查 / 止盈止损 / roll | 只有**固定持仓期 markout**：在 `t+h`（h∈{5,20,60} 个交易日）读一次结果。没有管理、没有止损、没有 roll |
| **P&L**：美元盈亏、按本金的收益率、净值/Sharpe/最大回撤 | 单位是 **vol points（波动率点）**，不是美元也不是收益率。`harvest = IV(t) − RV(t+h)`；`+0.08` 读作"**卖出的 IV 比后来实现的 RV 贵 8 个波动率点**" |
| **成本**：买卖价差、佣金、滑点、对冲成本 | **零成本、无摩擦**。一个理想化的上界 |

### 各"轴"的输出到底是什么单位

- **harvest（item 2/4）**：`IV(t) − RV(t+h)`，**vol points**。正值=空波动率头寸在波动率维度上赚了。**不是 $**。
- **directional（item 5a）**：`adj_price(t+h)/adj_price(t) − 1` 的 RICH−CHEAP 差值，**是标的的收益率**（最接近"P&L"的一个），
  但它是**标的多空收益差**，不是期权头寸盈亏。
- **ΔVRP（item 5b）**：`vrp(t+h) − vrp(t)`，**vol points 的变化**。描述 VRP 自身回归，不是盈亏。

### 为什么"vol points 的 harvest"≠ P&L

`harvest = IV − RV` 是一个**已实现方差风险溢价**的代理，约等于一个**持有到期、连续 delta 对冲**的空头跨式/方差互换的
*理想化*盈亏方向。要把它变成美元 P&L，需要：

1. **选结构**（且必须**定义风险** —— 本项目铁律：禁裸卖。空跨式是裸的，得用 iron condor / 信用价差 / 带保护腿的结构）。
2. **vol points → $ 的换算**：跨式≈ `vega × (IV − RV)`（一阶）；方差互换≈ `notional × (IV² − RV²) / (2·strike)`。
3. **真实成交价**：用 `t` 时的期权 mid/价差，而不是抽象的 IV。
4. **gamma/对冲路径**：空跨式的真实盈亏依赖**路径**，由每日 delta 对冲捕获 —— markout 的 `IV−RV` 是"对冲到期"的*理想*值，
   真实对冲有离散化误差 + 成本。
5. **出场规则**：固定 T+20 vs 21-DTE 复查 vs 止盈/止损（叠加 swing 默认 + **绝不持仓穿越财报**）。
6. **摩擦**：买卖价差、佣金、滑点。
7. **仓位 + 组合**：sizing → 净值曲线 → Sharpe / 最大回撤 / 命中率。

### 那这份研究的价值是什么？

它建立了一个策略的**前置条件**：edge **存在且样本外稳定**（溢价为正、过 walk-forward 留出 + 逐季度灾难闸）。
这是"**值不值得去搭真回测**"的筛子 —— 先证明 edge 在、再去付工程代价建 entry/exit/P&L。当前结论：
指数/信用/行业 ETF + 精选板块单票的 RICH 状态，**有稳定的、可去搭真回测的 vol-premium edge**；真回测的美元数会
比这里的 vol points **低**（被成本/对冲吃掉一部分）。

> **数据齐不齐？** 大部分齐了：`vrp_daily` 有 IV、`realized_volatility_history` 有价格、markout 机器在。
> 缺的是**期权结构定价 + 对冲模型**（把 vol points 翻译成定义风险结构的美元盈亏）。这是下面 §9 列的下一步。

## 4. 方法论（含联网核验的引用）

- **精确前瞻 RV**：`sqrt(252) × 日 log 收益的样本标准差`，与现有 `volatility_series._fill_rv_from_price`
  的口径一致（pandas `.std()` 即 ddof=1）。窗口用 `horizon` 个收益（持仓期本身），这正是与"trailing-21d
  近似"的差别 —— item 1 量化的就是这个差。约定核验：Wikipedia *Volatility (finance)* / AnalystPrep FRM。
- **拆股/分红回填**：拆股必调（大跳空会毁掉 RV）；分红默认**关**（季度除息只有 ~0.5% 跳空，对 RV 二阶，
  且打开会把方向性研究悄悄变成 total-return 研究）。一个"未调整拆股"防线：单日 |log 收益| > 0.5 直接丢弃该窗口。
- **历史财报日历（item 3）**：`massive_fundamentals.filing_date` ∪ `flow_events.next_earnings_date`。
  联网核验：8-K 财报新闻稿（真正的跳空日）领先 10-Q **0–14 天**（KnownTrends / Calcbench），所以
  filing 来源的日期带 **15 个自然日的向后缓冲**，flow 来源（即公告日）缓冲 0。
- **OOS 纪律**：沿用 skew/VRP 的 walk-forward 留出（后 40%）+ **逐季度灾难闸**。置信度最高 "med"。
- **方向性（item 5a）联网核验**：Bollerslev–Tauchen–Zhou —— 高 VRP（**水平/时序**）预测**高**未来收益。
  横截面去均值会把这个效应抹掉，所以方向性测试**不去均值**，改测 **RICH−CHEAP 的多空差值序列**，
  且 OOS 直接跑在这个差值序列上。

## 5. 实测结果（2026-06-22 本地预跑，已做 corp-action 调整）

### 5.1 item 1 —— 近似到底有多松？（vrp_rv_validation 摘要）

| horizon | 标的数 | 平均 \|偏差\|（vol pts） | 平均 corr(近似, 精确) |

小盘（如 AAOI h=5 |偏差| 0.45）尤甚 —— 短窗精确 RV 只有 5 个收益、本身很吵。这证明 item 1 的前提成立：
harvest 应当用**精确 RV**（现在 `run_vrp_markout` 已切换）。

## 6. 三轴拼出的统一图景（内在联系的回报）

- **测量层**修正后，收成数字普遍更可信（拆股不再污染 RV，财报不再漏进窗口）。
- **持仓期轴**：溢价在 ~T+20 见顶，单票 T+60 衰减到不可卖。
- **条件轴**：单票可卖与否是**板块问题**，不是整体问题。
- **目标轴**：贵波动率不仅"收成正"，还**自身向下回归**、且对应的**单票还会跑输** —— 三个独立目标
  指向同一笔交易（在 RICH 时卖指数/信用/行业 ETF 以及精选板块单票的波动率，~一个月持仓）。

## 7. 工程决策

1. **测量层是共享核心**：`vrp_markout_core`（调整价 + 精确 RV + 通用 walk-forward/季度闸）被 harvest 与
   三个轴共同消费 —— 这是"内在联系"的代码化；不是五段拷贝的 markout。
2. **校正只作用于"目标"，不重算"信号"**：精确 RV 修正的是 harvest/方向性的**前瞻目标**；`vrp_z` 信号与
   ΔVRP 目标仍用 UW 口径的 `vrp_daily`（UW 独立计算，重算会偏离全站展示的 VRP）。item 1 的 validation
   量化了 UW-RV 近似与精确的差，也就间接框定了信号可能的偏差。
3. **无价格覆盖时回退**：`run_vrp_markout` 在标的无价格序列时回退到 UW `vrp_daily.rv`（降级、等价 v1）。
   生产里每个 vrp_daily 标的都源自 realized_volatility_history，所以跑的是精确路径。
4. **作业顺序**：corp-actions 17:35（OHLC 后）→ fundamentals 19:00（filing 财报腿）→ vrp_research 19:10
   （在 filing 之后，日历最新）。所有结果表**整表重写**，掉出的桶不会留下陈旧行。

## 9. 下一步（从 markout 到可交易回测）

研究层已证明 edge 在。真正缺的、也是最有价值的下一步是把它**翻译成一个定义风险的、带 P&L 的策略回测**：

1. **定义风险的空波动率结构回测**（headline）：按 §3 的 7 点路线图建一个 `vrp_strategy_backtest` —— 在 RICH 信号入场，
   用**定义风险结构**（iron condor / 信用价差 / 带保护腿，**禁裸卖**），按 vega 或方差互换 notional 把 vol points 换成
   美元，叠加每日 delta 对冲路径 + 买卖价差/佣金，按持仓期或 21-DTE 出场，绝不持仓穿越财报，最后出**净值曲线 +
   Sharpe + 最大回撤 + 命中率**。范围先收在已判 SELLABLE 的桶（指数/信用/行业 ETF + Power/Space/Fintech… 板块单票）。
2. **接入决策面**：六张表目前**无人消费**。把 `HARVEST_SELLABLE` / 板块裁决 / 衰减曲线接进 option-wizard 的
   "波动率贵不贵、该不该卖"硬门控，或 regime 页一张卡（这是被砍掉的 UI 卡片的孪生后续）。
3. **校准持仓期**：item 4 显示 ~T+20 见顶 —— 真回测里把默认持仓期定在那儿，并验证 21-DTE 复查是否优于固定持仓。

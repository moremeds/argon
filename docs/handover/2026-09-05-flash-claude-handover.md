# Flash — executive summary and handover (2026-09-05)

For the Claude session that implements Flash in argon. Read this, then the
plan, then start. Nothing here is optional.

## What Flash is

The option-wizard daily options brief, generated by helium on the Mac mini,
rendered as a page inside argon instead of an email. Sidebar item **Flash**,
directly under Dashboard. Subtitle "agent news flash".

Information architecture, decided by the operator:

- Grouped by **trading week**. A week is 5 days + 1 **weekly summary & outlook**.
- A day's main report is **premarket**; **intraday** and **close** are
  supplements attached to that day.
- Monday's "Frank 复盘" (an external weekly review) is a supplement to OUR
  weekly summary & outlook, not to a day.

## Why it exists

Three email designs were rejected on looks. The root cause is email itself:
Gmail's 102 KB clip, table-cell charts, forced dark-mode inversion. A page in
argon removes all of it and gives history for free.

## Architecture (three layers; only the top one knows what a flash is)

1. `uw_scan.agent_runs` — generic, append-only, versioned; keyed by
   `(tenant, kind, run_day, version_no)`, idempotent on `(tenant, run_id)`.
   `view_jsonb` is opaque to argon. Migration `148_agent_runs.sql`.
2. `POST /api/agent-runs` behind a shared bearer token (`ARGON_INGEST_TOKEN`),
   plus reads: `/weeks`, `/week/{week_key}`, `/run/{kind}/{run_day}`, `/latest`,
   all parameterised by `tenant`. A neutrality test fails the build if
   tenant words (premarket, flash, strike, …) leak into the transport code.
3. Flash — `web/app/flash/**`, `web/components/flash/**`, tenant fixed to
   `option-wizard`, kinds `premarket | intraday | close | weekly | frank`.

The generic layers are deliberate: the operator will reuse this path for
other helium tenants. Do not let a Flash concept sink below layer 3.

## Decisions already made (do not reopen)

- weekly phase runs **Sunday 08:00 ET**; empty-state copy is
  "Generated Sunday morning", not "Friday after close".
- Frank source is verified on the helium side first (their Task 0); argon
  only needs to accept `kind = frank` rows.
- Design system is argon's own (`DESIGN.md`, dark tokens, Inter + IBM Plex
  Mono, hand-rolled SVG). Desktop wide layout. Not mobile, not email.
- Price tiles: label / value / change, uniform in every phase; at most 7 per
  row, rows balanced; no per-tile source line; no single-name tiles in the
  tape (SPY / QQQ / IWM / 10Y / DFII10 / VIX / HY OAS for premarket).
- Semantic colour only on numbers; never fill a panel green or red.
- No fabricated numbers anywhere, including fixtures: seed tests from the
  real 2026-09-03 run captured in the mock.

## Definition of done

- Migration 148 applies on a fresh DB and is a no-op on re-run.
- `POST /api/agent-runs` rejects a missing/wrong token, creates on first
  post, returns `created:false` on the identical re-post.
- Neutrality test passes.
- `/flash` renders the seeded 2026-09-03 week: Thursday with three phases,
  the other days as honest empty states, weekly view with Outlook and
  Frank slots; matches the mock at 1600 px.
- `npm run gen:types` output committed; `pnpm typecheck`, vitest, pytest
  green; Playwright e2e for the seeded row.

## The tool — `web/mcp/tools/ticker_snapshot.ts`

Input `{ ticker: string }` (upper-cased; missing → throws, mirroring T2's unknown-field error). Returns `{ ticker, technicals, chain_flow, term_move, flow_timeline, gamma_bar, charm, vanna, cockpit }`; every section is `{ as_of, …values }` or `{ error }`; a failed section never fails the call.

- `technicals`: `scanTicker(ctx, T, { fields: ["*"], timeframe: "1y" })` (T2's exported per-ticker row; shares the module-level EOD cache + 8-cap pool), wrapped with `as_of: { eod, live }`.
- `chain_flow` + `term_move`: **one** `apiGet("/stock/{T}/trade-insights")`, `as_of` = payload `as_of`, derived via `chainFlowRead` / `termMoveRead`.
- `flow_timeline` + `gamma_bar` + `charm` + `vanna`: **one** `apiGet("/stock/{T}")` shared by all four, `as_of` = `generated_at`; derived via `flowTimelineSeries` / `gammaBarTiles` / `sortByExpiry`+`defaultExpiry`+`netExposureCurve`+`netExposureTone`.
- `cockpit`: only for `SPX/SPY/QQQ/IWM` (mirrors `app/cockpit/[ticker]/page.tsx`), else exactly `null`. Three fetches (`vrp`, `dealer`, `state`); any failure → the whole section is `{ error }`. Carries `vrp` (points_n, stats, band, latest row + z), `dealer` (first-six expiry groups, totals, peaks on the primary expiry) and `state` pass-through (all `state.*` fields verbatim — `vrp_zscore_60d`, `vrp_zscore_252d`, `vrp_state`, …). `as_of` = `market_date`.
- `McpTool<typeof inputSchema>` with `ticker` declared `.optional()` — the registry's `McpTool` raw-shape default only accepts all-optional inferred args (T2's same decision); required-ness is enforced in-handler.
- Description lists the sections and the cockpit gate.

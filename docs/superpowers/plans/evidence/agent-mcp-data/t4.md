Extraction notes:

- The only adaptation is the clock: `quoteIsFresh` in `useRegimeQuotes` reads `Date.now()` internally, so `derive/gex.ts` carries the same body as `quoteIsFreshAt(quotedAt, freshWithinSeconds, now = Date.now())` and the other modules accept `now` the same way. Components call with the default (inside the lib, exactly where the original `quoteIsFresh` hid it); tests inject `now`.
- `liveSpotSelection` takes `data?.ticker`/`data?.tape_time` as primitives and `gexSpotRead` takes a `Pick<GexData, "spot"|"prev_close"|"day_change"|"day_change_pct">` literal — `data` is a `useMemo` dep in `GexSubTab`, and the React compiler (`react-hooks/preserve-manual-memoization`) treats dep objects handed to a cross-file callee as potentially mutated, which fails lint. Primitives-only call sites keep the memo preservable with zero logic change. Inside the memo, dep-derived args to `retagProfileForSpot` are fresh copies (`[...profile]`, `{ ...data.levels }`) — the same `{ ...data }` idiom T1 used in `TechnicalsPriceChart`.
- `quoteIsFreshAt` is exported from `derive/gex.ts` and shared by `volBackdrop.ts` — one clock-injected freshness helper, no second implementation.

## The tool — `web/mcp/tools/regime_state.ts`

No input. Returns `{ gex, vol_backdrop, cri, vcg, vrp_macro }`; every section is `{ as_of, …values }` or `{ error }` and a failed section never fails the call. `/regime/quotes` is fetched **once** and shared by gex + vol_backdrop; a failed quotes call degrades both to the EOD/no-live-quote path (the UI's same fallback) rather than erroring.

- `gex`: `apiGet("/regime/gex", { ticker: "SPX" })` → `{ as_of: scan_time, spot, live_spot, display_spot, day_change, day_change_pct, levels, flip, profile }`. `profile` is retagged via `retagProfileForSpot` only when a live spot was used (mirrors the `liveProfile` memo); otherwise payload buckets pass through with their own field names (`strike`, `pct_from_spot`, `tag`, `net_gex`, …).
- `vol_backdrop`: `apiGet("/regime/vol-backdrop")` + shared quotes → `{ as_of: as_of, ratio, state, ratio_source: live|eod, symbols: {VIX|VIX3M|VVIX|COR1M: {live, last, change_pct}} }` via `termStructureRead` + `symbolRead`.
- `cri`: `apiGet("/regime/cri/live")` → `{ as_of: scan_time, basis, score, level, composite_version, components, prior_components, vix_delta_3d, spx_last, history_as_of }`. `prior_components` = `priorComponentScore(priorHistoryRow(live), slot)` per slot; `vix_delta_3d`/`spx_last` are the last values of `vixDelta3dSeries`/`spxMedianFiltered` over `apiGet("/regime/cri/history", { days: 90 }).rows`.
- `vcg`: `apiGet("/regime/vcg/live")`, falling back to `apiGet("/regime/vcg")` when live throws. Pass-through of the state fields (`status`, `scan_time`, `date`, `credit_proxy`, `signal`, `basis`, `live_quotes`, `carried_forward`, `active_source`) minus the bulky `history` array; `as_of` = `scan_time`, `basis` = payload `basis` or null on the EOD shape.
- `vrp_macro`: `apiGet("/regime/vrp-macro-signal/live")`, falling back to `/regime/vrp-macro-signal`. Live shape passes through `{ status, basis, signal, live_quotes, active_source }`; EOD passes through `{ signals }`. Neither has a top-level timestamp, so `as_of` = max `snapshot_date` across the row(s) (the field the payload documents as "when the job ran"; the vol-data date stays inside each row's own `as_of`).

## Notes / deviations

- `liveSpotSelection`/`gexSpotRead` take primitives (`ticker`, `tapeTime`, a `Pick` literal) instead of `data` — required for the React compiler's dep-mutation analysis (`react-hooks/preserve-manual-memoization`); bodies and outputs are verbatim.
- `gexSpotRead` drops `spotTapeTime` (it moved into `liveSpotSelection`, where `tape_time` is already a parameter) — the component destructures the same rendered values.
- Clock injection uses `now = Date.now()` default params, so components don't call `Date.now()` in render (react-hooks/purity); identical semantics to the original `quoteIsFresh`.
- `vrp_macro.as_of` uses row `snapshot_date` (payload has no top-level timestamp); each row's own `as_of` stays passed through.
- `vcg`/`vrp_macro` fall back to EOD only when the live call throws — a `status:"empty"` live payload passes through as-is (the endpoints self-report `basis:"eod"` when they internally degrade).

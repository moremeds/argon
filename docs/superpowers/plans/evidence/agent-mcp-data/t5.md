## The tool — `web/mcp/tools/market_overview.ts`

No input. `apiGet("/watchlist")` and `apiGet("/watchlist/chains")` issued in parallel (chains promise created before the awaited watchlist call — same split as `lib/dashboardData.ts`): a chains failure yields `chains: []` + `chains_error`; a watchlist failure propagates as the tool error.

- Returns `Columnar` (`{as_of, columns, rows}`) plus top-level `chains`, `scheduler_lag_seconds`, `queue` (payload pass-through).
- `columns`: `ticker, sector, group, chains, pinned, hot, spot, spot_quoted_at, iv_atm, iv_rank, market_cap, aum, setup, aggression_pct, returns, gamma, skew, positioning`. `sector` is the card field; `group` is the `orderCards` sector-group key (identical string today; kept as separate columns per spec). Card `chains` is the card's own chain-membership array; top-level `chains` is the rail payload.
- Rows are in `orderCards` order; **all values are verbatim `/watchlist` fields** — `spot` stays the server's string, `returns`/`gamma`/`skew`/`positioning`/`setup` pass through as objects. No card numbers re-derived.
- `as_of.eod` = payload `scanned_at_max`; `as_of.live` = the max `spot_quoted_at` across cards by `Date.parse` (the raw string is emitted, no re-formatting).
- Description names the columns and states verbatim-server-values + grid order.

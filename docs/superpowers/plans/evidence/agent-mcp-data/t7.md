## What changed

### 1. Unvalidated ticker → path traversal — new `web/mcp/lib/ticker.ts`

`normalizeTicker(raw)` = trim → upper-case → require `/^[A-Z0-9.^-]{1,10}$/` (`TICKER_RE`, exported `i`-flagged for the zod schemas) → reject all-dots values (`..`). Allows BRK.B / BRK-B / ^VIX; rejects `/`, `%`, `#`, `?`, whitespace, `..`. Throws `Error("invalid ticker: <raw>")`.

Applied:

- `technicals_scan` schema: `tickers: z.array(z.string().regex(TICKER_RE))`; `ticker_snapshot` schema: `ticker` keeps `z.string().min(1)` + `.regex(TICKER_RE)`.
- `technicals_scan` handler: `args.tickers` normalize eagerly (bad arg → whole call rejects, same as the schema rejection on the wire); watchlist-derived tickers normalize per row — a poisoned watchlist entry is that row's `error`, not a failed scan.
- `scanTicker` validates its `ticker` arg (directly callable).
- Every `${ticker}`/`${T}` path interpolation wrapped in `encodeURIComponent` (defence in depth): `/stock/{}/technicals`, `/technicals/live`, `/magnets` in technicals_scan; `/stock/{}/trade-insights`, `/stock/{}`, `/cockpit/{}/vrp|dealer|state` in ticker_snapshot. (`regime_state` has no ticker path — `/regime/gex` passes `ticker` as a query param, already URLSearchParams-encoded.)

### 2. EOD cache key covers `uw_scan.technical_vwap_anchor`

One query: `max(inserted_at)` over `technical_daily` `|| '|' ||` `count(*) ':' max(computed_at)` over `technical_vwap_anchor`. `count` catches anchor deletes, which don't move the max; `computed_at` moves on POST/DELETE vwap-anchor (repository upsert sets `computed_at = now()`).

### 3. Freshness `now` read per ticker at merge

`loadTicker` drops its `now` opt and calls `mergeLiveHead(eod, live, Date.now())` after that ticker's live payload arrives — same as the page evaluating at render. A mid-scan capture no longer gets a negative age against the scan-start clock. (The EOD-key throttle keeps the scan-start `now` — it's a TTL gate, not a freshness check.)

### 4. sma fields vs the spliced live row

- `sma200` → `data.header.sma200` (the KPI-strip tile source, `TechnicalsKpiStrip.tsx:49`).
- `sma20` / `sma50` / `rs_ratio` → last `eod.series` row — the appended live row carries none of them (live payload is the fast-moving subset only); code comment says so.

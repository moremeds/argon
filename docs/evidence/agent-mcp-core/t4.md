## What was built

- `web/package.json` script (scripts block only):
  `build:mcp` = `esbuild mcp/server.ts --bundle --platform=node --format=esm
  --banner:js="import { createRequire } from 'node:module'; const require =
  createRequire(import.meta.url);" --external:pg-native
  --external:lightweight-charts --external:fancy-canvas
  --outfile=.mcp-dist/server.mjs`. The createRequire banner is REQUIRED —
  `pg` (CJS) does `require("events")` internally and the ESM bundle crashes
  without it (`Dynamic require of "events" is not supported`, found in Task 2).

  `server.js`. Web `CMD ["node", "server.js"]` UNCHANGED — the compose `mcp`
  service will run `command: ["node", "mcp-server.mjs"]`.
- Pre-merge gate: `git merge --no-edit origin/feat/agent-mcp` pulled C's work

```
$ docker run --rm -d --name mcp-test -p 8500:8500 \
    -e MCP_DATABASE_URL=postgres://chenxi@host.docker.internal/option_wizard_local \
    -e ARGON_API_URL=http://host.docker.internal:8400 -e MCP_PORT=8500 \
    argon-web:mcp-test node mcp-server.mjs
$ docker logs mcp-test   → argon-mcp listening on :8500 (api: http://host.docker.internal:8400)
$ curl http://127.0.0.1:8500/healthz            → {"ok":true}
$ curl -X POST http://127.0.0.1:8500/mcp -d '{}' → 401 (auth layer active)
$ docker stop mcp-test; docker rmi argon-web:mcp-test   → removed
```

Note: host Postgres is `listen_addresses=localhost`, so in-container DB
connects fail — mcp-server.mjs still boots (Pool is lazy) and fails closed
(401, not 500) on authed paths; the compose `mcp` service will run on the
compose network where the DB is reachable. The bundle is self-contained
(node_modules not needed in the runtime image).

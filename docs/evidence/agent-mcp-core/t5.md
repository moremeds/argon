# Task 5 evidence — compose services, role SQL, runbook, local e2e

Plan A5. Files: `docker-compose.yml`, `scripts/ops/mcp_role.sql` (new),
`docs/runbooks/agent-mcp.md` (new).

## What was built

- `docker-compose.yml` — two new services (post-review secret-exposure fix:
  the public-facing pair must NOT hold `/opt/argon/.env` — argon_app password
  + provider keys — they read a dedicated `/opt/argon/mcp.env`):
  - `mcp`: `ghcr.io/moremeds/argon-web` image (same build as web),
    `command: ["node","mcp-server.mjs"]`, NO `*common` — `restart:
    unless-stopped`, `env_file: [/opt/argon/mcp.env]` only, `extra_hosts`
    host-gateway, watchtower label, no lake volume;
    `ARGON_API_URL=http://api:8400`, `MCP_PORT=8500`,
    `127.0.0.1:8500:8500` loopback-only publish, wget `/healthz` healthcheck
    (explicit IPv4), `depends_on api:service_healthy`.
  - `cloudflared`: `cloudflare/cloudflared:2026.9.3` (tag verified by
    `docker pull` — `cloudflared version 2026.9.3`), `tunnel --no-autoupdate
    run`, `env_file: [/opt/argon/mcp.env]` only (TUNNEL_TOKEN),
    `depends_on: mcp`.
- `scripts/ops/mcp_role.sql` — `argon_mcp LOGIN` in a DO-block guard (no
  password — operator sets via `\password`/`.env`); `USAGE` schema, `SELECT
  ON ALL TABLES`, `ALTER DEFAULT PRIVILEGES FOR ROLE argon_app` (future
  tables), `INSERT mcp_access_log`, `SELECT,INSERT,UPDATE mcp_event_cursor`,
  `USAGE ON SEQUENCE uw_scan.mcp_access_log_id_seq` (mcp_event_cursor has no
  sequence — noted in-file).
- `docs/runbooks/agent-mcp.md` — named-tunnel setup (mcp.rsiarc.com →
  http://mcp:8500), `/opt/argon/.env` vars, role SQL, `control-argon
  mcp-token` inside the api container, Grok/OpenAI config (URL + Bearer).

## Deviations

- `docker compose config` validated via an env-file-path-substituted copy —
  `/opt/argon/*.env` exist only on the mini.
- API started as a direct `uvicorn` (not `control-argon up`) — smaller blast
  radius alongside other worktrees' processes; sanctioned by the task note.
- Watchtower label kept on mcp (not in the lead's field list) — same image
  as web; without it the tunnel-side service would silently pin a stale
  bundle on every web redeploy.

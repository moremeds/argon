# Task 3 evidence — `read` + `list_endpoints` tools

Plan A3. Files: `web/mcp/lib/openapi.ts` (new), `web/mcp/lib/endpoints.ts` (new),
`web/mcp/tools/read.ts`, `web/mcp/tools/list_endpoints.ts`,
`web/tests/unit/mcpReadEndpoints.test.ts` (new).

## Design points (spec-mapped)

- Allowlist = GET operations from the internal API's `/openapi.json`:
  `parseOpenApiEndpoints` keeps only ops with a `get`, strips the `/api`
  router prefix (same path universe `apiGet` speaks), sorts; `DENYLIST`
  (exported `ReadonlySet`, empty) is applied at parse time.
- `/openapi.json` lives at the FastAPI APP ROOT (`FastAPI()` default
  `openapi_url`; verified `src/uw_scan/api/server.py`), NOT under `/api` —
  `ctx.apiGet` (which prepends `/api`) cannot reach it → new GET-only helper
  `web/mcp/lib/openapi.ts` (`fetchOpenApiDoc`, `resolveApiBase` =
  `ARGON_API_URL ?? http://api:8400`, second GET-only fetch site in web/mcp).
- `EndpointsCache`: first call fetches, single-flight dedupe, refetches when
  older than 1 h, failed refresh serves stale copy (cold-start failure throws).
- `matchEndpoint`: segment-wise `{param}` template matching (exact count,
  non-empty segment required).
- `read(path, params)`: rejects `%`/`.`/`..`/`//` in the raw path before any
  fetch — WHATWG decodes percent-encoded dot segments inside fetch, so
  `%2e%2e` would otherwise bypass the literal checks (herd-reject fix);
  tolerates a leading `/api/`; fills `{placeholder}` segments from `params`
  (url-encoded, removed from query; `.`/`..` values rejected — dots survive
  encodeURIComponent); rejects unresolved/unmatched paths with
  `'...' is not an allowlisted GET endpoint. Call list_endpoints()`;
  allowlisted → `ctx.apiGet(resolved, remainingParams)` (GET only).
- `list_endpoints()` → `[{path, summary, params:[{name,in,required}]}]`.
- `tools/index.ts` + `types.ts` untouched (lead-owned); `McpTool` stays
  unparameterized (generic contravariance breaks `TOOLS: McpTool[]`), args
  cast inside the handler.

## Deviations

- `ctx.apiGet` cannot reach `/openapi.json` (it prepends `/api`; FastAPI serves
  the doc at app root) — added `web/mcp/lib/openapi.ts` `fetchOpenApiDoc`, a
  second GET-only fetch site reading `ARGON_API_URL`. Sanctioned by lead's
  Task 3 instructions.
- `uv sync --extra postgres` run (lead-specified; bare `uv sync` strips the
  postgres extra → `psycopg_pool` missing → uvicorn import fails).
- `list_endpoints` lazy-fetches on first call rather than at process boot —
  same observable behavior (server has no hook point outside tools without
  touching lead-owned files), single-flight dedupe makes the first call safe.

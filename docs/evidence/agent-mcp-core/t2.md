# Task 2 evidence — `web/mcp/server.ts` (transport, auth, access log, SSE)

Plan A2. Files: `web/mcp/server.ts` (new), `web/tests/unit/mcpServer.test.ts` (new).

## Design points (spec-mapped)

- `node:http` + `StreamableHTTPServerTransport` (`sessionIdGenerator: randomUUID`
  — stateful, needed for the standalone SSE stream). Routes: `POST|GET|DELETE
  /mcp`, `GET /healthz` (no auth).
- Bearer auth before the transport: `sha256(token)` → `mcp_token` where
  `revoked_at IS NULL`, **one lookup per request — revocation is effective on
  the very next request, including on an already-open session** (herd-reject
  fix: 60 s positive cache removed). 401 + `WWW-Authenticate: Bearer` on failure.
- Sessions bind the authed label: a different valid token on a foreign session
  → 403; unknown session → 404; non-initialize POST without session → 400.
- Session lifecycle (`SessionStore`, herd-reject fix — sessions used to live
  forever since cloud agents rarely DELETE): `lastSeen` touched on every
  session request; one unref'd `setInterval` (60 s) sweeps sessions idle
  > 30 min via `transport.close()` + delete; a live standalone SSE stream
  (`sseOpen`) exempts its session; dead SSE socket → `sseOpen=false` +
  `lastSeen` reset → reaped 30 min later. Clock injectable via
  `HandlerOptions.now` for tests.
- Per-session `McpServer` registers every `TOOLS` entry (zod `inputSchema`);
  `wrapToolHandler` writes one `mcp_access_log` row per call (label, tool,
  args, ok|error, response bytes, duration); log-write failure is caught and
  logged, never breaks the call.
- `apiGet`: the ONLY `fetch` in the module — `fetch(base + "/api" + path + qs,
  {method: "GET"})`, throws on non-2xx. No other verb exists.
- SSE: on each GET stream, `subscribeEvents(ctx, send, close)` is called
  before `transport.handleRequest`; `send` maps to `transport.send` of a
  `notifications/argon_event` JSON-RPC notification (contract surface for C);
  `close` → `transport.closeStandaloneSSEStream()` (f74bfb6d); keepalive
  `: keepalive` comment every 30 s; `res.on("close")` unsubscribes + clears.
- Env: `MCP_DATABASE_URL` (required), `ARGON_API_URL` (default
  `http://api:8400`), `MCP_PORT` (default 8500).

## Verification

### typecheck + vitest

```
$ cd web && npx tsc --noEmit          # exit 0, whole project
$ npx vitest run tests/unit/mcpServer.test.ts
 Test Files  1 passed (1)   Tests  13 passed (13)   # exit 0
```

Tests cover: bearer parsing, sha256 hash, labelForToken SQL (sha256 vs
mcp_token + revoked_at IS NULL), immediate revocation over real HTTP
(initialize → token invalidated → same-session next request 401 + re-init
401), SessionStore.sweep with injected clock (idle closed+deleted, fresh kept,
live-SSE exempt, touch keeps alive), access-log ok + error + non-object
payload + log-failure non-fatal, apiGet URL/params/GET method/throw-on-error.

### live smoke (esbuild bundle + option_wizard_local + CLI-minted token)

```
$ npx esbuild mcp/server.ts --bundle --platform=node --format=esm \
    --banner:js="import { createRequire } from 'node:module'; \
    const require = createRequire(import.meta.url);" \
    --external:pg-native --external:lightweight-charts \
    --external:fancy-canvas --outfile=../output/mcp-smoke.mjs
$ MCP_DATABASE_URL=postgres://chenxi@127.0.0.1/option_wizard_local \
    MCP_PORT=8500 node ../output/mcp-smoke.mjs
```

NOTE: the createRequire banner is REQUIRED — `pg` (CJS) does `require("events")`
internally; without it the ESM bundle crashes (`Dynamic require of "events" is
not supported`). This flag goes into `build:mcp` in Task 4.

```
GET  /healthz                      → 200 {"ok":true}
POST /mcp (no bearer)              → 401
POST /mcp initialize + bearer      → 200, SSE response, mcp-session-id set,
                                    capabilities {tools:{listChanged:true}}
POST notifications/initialized     → 202
POST tools/list                    → 7 tools (all stubs registered)
POST tools/call read (stub throws) → {isError:true, "read: not implemented"}
mcp_access_log                     → 1 row: smoke_t2 | read | error | 0 bytes
GET  /mcp + session + Accept:sse   → 200 text/event-stream, held open
POST with unknown session id       → 404
POST other valid token + session   → 403
POST never-seen revoked token      → 401
```

Post-fix smoke (immediate revocation on a live session, token minted then
revoked via `control-argon mcp-token` while the session stayed open):

```
POST tools/list + session          → 200
$ uv run control-argon mcp-token revoke smoke_t2b   → [ok] revoked
POST tools/list + same session     → 401   (immediate — no cache window)
```

All smoke tokens revoked afterwards; server killed. `output/` is gitignored.

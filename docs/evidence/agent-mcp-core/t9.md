# Task 9 — round-3 review fixes (Astra + Fable)

Baseline: `feat/agent-mcp-core` ff'd to `dc970507` (A+B+C + preview route).
Ten findings fixed, one commit.

1. **HIGH — mutating/background GET denied.** Added
   `/stock/{ticker}/volatility/series` to `DENYLIST` — its GET schedules
   `_kick_backfill` via `BackgroundTasks` (routers/volatility.py:138-160) →
   DB writes + UW spend. New guard test
   `tests/unit/api/test_mcp_get_side_effects.py`: builds the app, flags every
   GET route whose endpoint signature takes `BackgroundTasks`, plus the known
   writer `/stock/{ticker}/trade-insights`, and asserts each is in the
   DENYLIST literal parsed from `endpoints.ts`. A second assertion pins every
   denylist entry to a real served GET route (typo'd entries can't silently
   fail to deny).
2. **MEDIUM — secrets split (chose two env files).** `mcp` reads
   `/opt/argon/mcp.env` (now ONLY `MCP_DATABASE_URL`); `cloudflared` reads
   `/opt/argon/cloudflared.env` (only `TUNNEL_TOKEN`). Verified via
   `docker compose config` (env paths sed'd to /tmp): mcp env =
   `{ARGON_API_URL, MCP_DATABASE_URL, MCP_PORT}`, cloudflared env =
   `{TUNNEL_TOKEN}` — neither carries the other's secret. Runbook §2 updated.
   Picked two files over `environment:` interpolation because compose
   interpolates `environment:` from the project `.env` — the file the secrets
   must stay OUT of.
3. **MEDIUM — hub listeners detached before release.** `Hub` now stores its
   bound `onNotification`/`onError`; `detachAndRelease` `off()`s both before
   `release()` on all three paths (last-unsub, error teardown, LISTEN
   failure). Test: 3 subscribe/unsub cycles on one reused client → listener
   counts back to baseline, then 1 notification = exactly 1 SELECT.
4. **MEDIUM — subscribeEvents failure no longer opens the stream.** Catch
   path clears the keepalive, leaves `sseStreams` at 0 and answers 503; the
   client reconnects. Test asserts the 503.
5. **LOW — stream counter instead of `sseOpen` bool.** `Session.sseStreams`
   increments only after `transport.handleRequest` returns with
   `statusCode === 200` and `!resClosed`; `res.on("close")` decrements only if
   this stream counted. A 409'd second GET can no longer clear stream 1's
   exemption. Sweep exempts `sseStreams > 0`. Test: second GET's unsub runs,
   stream 1's does not until its own close.
6. **LOW — param values validated raw, encoded, and not re-`%`-checked.**
   `badParamValue` rejects `/`, `\`, control chars, empty, `.`/`..`; then
   `encodeURIComponent`; the resolved path re-check passes `allowPercent` since
   our own encoding legitimately produces `%XX`. `^VIX`/`A&B`/`50%`/`BRK.B`
   via params now work; `AAPL/x`, `../x`, `a\nb`, `.`/`..`/empty still fail.
7. **LOW — `apiGet` gets `signal: AbortSignal.timeout(30_000)`**; test asserts
   the AbortSignal reaches fetch.
8. **LOW — SDK-rejected calls now log one row.** `buildMcpServer` wraps the
   underlying `server.setRequestHandler` for `CallToolRequestSchema` only:
   `isError` results without the `ACCESS_LOGGED` symbol (stamped on `extra` by
   `wrapToolHandler` — the same `extra` object reaches the tool handler)
   write a `status='error'` row. Unknown tool + schema-invalid + a
   handler-thrown failure each produce exactly one row (tested end-to-end
   over HTTP).
9. **LOW — runbook.** §4 notes `/opt/argon/compose.yml` is mirrored by hand
   (points at docker-deploy.md) so the mcp+cloudflared blocks must be added
   there; `\password argon_mcp` split into its own interactive psql step;
   failure table names `cloudflared.env`.
10. **LOW — mcp_role.sql comment.** PUBLIC holds EXECUTE on functions by
    default — the role can't be stripped of it; but no reachable function is
    SECURITY DEFINER (verified: `pg_proc.prosecdef` empty in `uw_scan`), so a
    mutating call runs with the caller's read-only rights and fails on write.
